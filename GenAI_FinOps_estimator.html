Total Cost of Ownership Estimator

Describe a GenAI product. The tool states the assumptions it had to make, sets the LLM tier, forecasts three years of adoption, and prices the same application on all four infrastructure models — the vendor bill and the people needed to run it, in Swiss francs. It then blends the four into one path through the adoption phases, and asks how many applications it would take before owning the hardware pays.

Prices, salaries, adoption coefficients, GPU throughput and hardware costs are fixed tables from the paper's annexes, in Swiss francs. All arithmetic runs in this page, in JavaScript, and every figure it prints is reproduced by the accompanying notebook. This is the offline copy submitted with the report: it opens from disk with no account, no key and no network. The three use cases from the report carry their parameters and their commentary with them. Describing an application of your own is the one thing that needs a Claude session, because that is the only step a language model performs — reading a free-text description to set the parameters. It never does the arithmetic.
